# 🛒 Shoppinglyx - Django E-commerce Website

## 📌 Overview
Shoppinglyx is a full-featured **e-commerce web application** built using Django.  
It allows users to browse products, add items to cart, place orders, and make secure payments.

This project demonstrates real-world backend development skills including authentication, payment integration, and scalable architecture.

---

## 🚀 Features

- 👤 User Authentication (Login / Signup)
- 🛍️ Product Listing & Categories
- 🛒 Add to Cart / Remove from Cart
- 💳 Payment Integration (Razorpay)
- 🔍 Product Filtering & Search
- 🖼️ Product Image Upload
- 🧑‍💼 Admin Dashboard

---

## 🛠️ Tech Stack

- **Backend:** Django, Django REST Framework  
- **Database:** SQLite 
- **Payments:** Razorpay
- **Frontend:** HTML, CSS, JavaScript  
- **Libraries:** Pillow, django-filter
